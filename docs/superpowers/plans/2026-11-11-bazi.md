# BaZi (Four Pillars) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Traditional Zi Ping BaZi on Stella: natal pillars and reading data, luck pillars, and time pillars for any instant, as three MCP tools backed by one calculation module.

**Architecture:** `bazi_tables.py` holds every lookup table (stems, branches, hidden stems, Nayin, Ten God relations, interactions, stars). `bazi.py` computes: pillars from a civil instant (with true solar time and the day-boundary rule), analysis, luck pillars and time pillars, returning plain dicts. `bazi_render.py` turns those dicts into Markdown. Tool functions in `stella_server.py` load the chart, call `bazi`, and return either Markdown or JSON. Month and year boundaries come from `ki_calendar.lichun_jd` and `ki_calendar.boundaries_jd`; nothing else is shared with Ki.

**Tech Stack:** Python 3.11, pyswisseph (`swe.time_equ`, `swe.julday`), `zoneinfo`, pytest, FastMCP.

**Spec:** `docs/superpowers/specs/2026-11-10-bazi-design.md`

## Global Constraints

- Python 3.11, stdlib plus pyswisseph. No new packages. No Helios calls except the existing chart loader.
- Nothing from `ki.py`, `ki_solar.py`, `ki_levels.py`, `octave*.py` or `hub_inheritance.py` is imported. Only `ki_calendar.lichun_jd`, `ki_calendar.boundaries_jd`, `ki_calendar.sun_at` and `ki_calendar.jd_to_local`.
- Every stem, branch and Ten God in output carries Chinese, pinyin and English.
- Defaults: `true_solar_time=True`, `day_boundary="23:00"`. Both appear in every tool docstring.
- Tool count in `tests/test_tool_registry.py` rises from 88 to 91.
- Reference fixtures (clock time, from buyiju.com on 2026-11-11, which uses no solar-time correction):
  - Betsy, 1978-11-20 22:31 New York: 戊午 癸亥 丙戌 己亥. Stem Ten Gods 食神 正官 日主 傷官; primary-qi Ten Gods 劫財 七殺 食神 七殺; Nayin 天上火 大海水 屋上土 平地木.
  - Chris, 1986-05-01 14:35 New York: 丙寅 壬辰 乙巳 癸未. Stem Ten Gods 傷官 正印 日主 偏印; primary-qi 劫財 正財 傷官 偏財; Nayin 爐中火 長流水 佛燈火 楊柳木.
  - 2000-01-01 00:30: 己卯 丙子 戊午 壬子. Stem Ten Gods 劫財 偏印 日主 偏財; primary-qi 正官 正財 正印 正財; Nayin 城頭土 澗下水 天上火 桑柘木.
  - Day anchors: 1900-01-01 甲戌; Mao Zedong 1893-12-26 辰時: 癸巳 甲子 丁酉 甲辰.

## Review Focus

- A birth whose true solar time crosses the 23:00 boundary but whose clock time does not: the day pillar must change under the default settings (Task 2).
- A birth in the hour before Lichun or before a jie: the year or month pillar must be the previous one, by the exact instant, not the calendar date (Task 1).
- Historical DST: `zoneinfo` must be asked for the standard offset at that instant, not the DST offset, when deriving the zone meridian (Task 2).
- A stored chart in the older `birthData` shape with no gender: tools must still return pillars and must omit luck pillars with a stated reason (Task 6).
- A branch that appears twice in the chart (Betsy has two 亥): every interaction and star is reported once per pillar pair, never collapsed and never duplicated (Task 4).
